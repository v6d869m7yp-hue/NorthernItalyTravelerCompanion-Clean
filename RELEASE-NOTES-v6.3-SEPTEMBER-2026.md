# Northern Italy Traveler Companion v6.3

## Unified Navigation System

- Replaced inconsistent page-by-page header links with one generated publication navigation.
- Added grouped Plan, Travel Tools, Destinations, and More Destinations menus.
- Added a searchable tablet/phone navigation drawer.
- Standardized current-page states and breadcrumbs.
- Integrated Ctrl/Cmd+K with the unified navigation search.
- Removed the separate floating Quick Jump control to reduce competing navigation patterns.
- Preserved the Trip Mode travel dock as an in-trip utility rather than a second site menu.
