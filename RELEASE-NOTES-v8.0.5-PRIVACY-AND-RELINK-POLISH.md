# Northern Italy Traveler Companion v8.0.5

## Privacy & Relink Polish

- Cloud reservation forms now accept only shared itinerary facts.
- Confirmation numbers, payment information, private contacts, access details and sensitive notes are directed to the encrypted Travel Vault.
- Shared document uploads clearly state that authorized trip members can view them.
- A separate encrypted-Vault action is provided for private files.
- Existing encrypted private reservation records can be relinked when Firebase reservation IDs change, using a conservative name-and-date match.
- Multiple-file reservation uploads and the Safari recovery fix are preserved.

No encrypted user data is included in this release package.
