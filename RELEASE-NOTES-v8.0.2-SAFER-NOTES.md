# Northern Italy Traveler’s Companion v8.0.2 — Safer Notes Polish

## Security and privacy changes

- Removed all editable hotel booking-note fields from the public Stays page.
- Removed legacy browser-local hotel note values on page load.
- Replaced local note controls with a direct link to the signed-in Companion reservation area.
- Clarified that confirmation numbers, access instructions, host contacts and traveler-specific details must not be stored on public pages.
- Updated release labels and the offline cache identifier to v8.0.2.

## Scope

General hotel names, check-in guidance, route planning and destination links remain available publicly. Sensitive reservation records belong only in the authenticated Companion backend.
