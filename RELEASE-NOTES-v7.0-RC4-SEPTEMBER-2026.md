# v7.0 RC5 — Simple Menu Restoration

- Removed the nested publication navigation and persistent side drawer.
- Restored one Menu button with a simple flat list of primary pages.
- Uses the native `hidden` attribute as the authoritative open/closed state.
- Closes after link selection, outside click, Escape, page restore, and orientation change.
- No hover menus, nested accordions, or desktop menu panel.
