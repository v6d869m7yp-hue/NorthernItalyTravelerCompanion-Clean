# Northern Italy Traveler Companion v6.1 — Publication Foundation

This deliberately limited release introduces the shared publication foundation without restructuring page templates.

## Added
- Central color, spacing, radius, shadow, type, and layout tokens.
- One responsive typography hierarchy for display, page, section, card, lead, and body text.
- Shared card/surface rules and consistent control sizing.
- Unified focus-visible and reduced-motion behavior.
- Stable foundation breakpoints for desktop, tablet, and phone.
- Explicit LF line-ending policy through `.gitattributes`.

## Intentionally deferred
- Hero component migration.
- Destination and hotel template restructuring.
- Navigation redesign.
- Map redesign.

Those changes remain staged for later releases so this foundation can be verified independently.
