# Northern Italy Traveler Companion v8.0.3

## Multiple reservation screenshots

- Travel Documents now accepts up to 12 files in one selection.
- Multiple screenshots are uploaded as separate, clearly numbered document records linked to the same reservation.
- The upload dialog shows a file list, sizes, combined progress, and a clear maximum.
- Editing an existing document still allows one replacement file to avoid accidental data loss.
- All files remain in the authenticated Firebase Storage area for the active trip.
