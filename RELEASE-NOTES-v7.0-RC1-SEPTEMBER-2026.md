# Northern Italy Traveler Companion v7.0 RC2

## Release-candidate focus

This release freezes feature development and performs a full-site publication polish and quality-assurance pass.

### Improvements
- Unified responsive safeguards for desktop, iPad portrait/landscape, and phone layouts.
- Safer hero and heading widths to prevent clipping and unintended truncation.
- Standardized readable content widths, tap targets, focus indicators, and high-contrast behavior.
- Image loading prioritization: first-page imagery loads eagerly; secondary imagery lazy-loads.
- Improved offline strategy with network-first page navigation and cached static assets.
- Added page descriptions, external-link safety, semantic heading corrections, reduced-motion and print refinements.
- Updated all active asset versions, manifest details, service-worker cache, and visible release labels.

### RC acceptance criteria
- No missing internal assets or links.
- Valid JavaScript and service-worker syntax.
- One accessible primary heading per page.
- No unlabeled images or controls.
- ZIP integrity verified.
